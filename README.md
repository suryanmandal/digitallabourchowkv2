# Digital Labour Chowk (DLC) V2

> India's Leading Construction Workforce Platform connecting daily wage craftsmen, contractors, builders, and nationwide EPC infrastructure enterprises.

---

## 🏗️ Overview

**Digital Labour Chowk (DLC)** is a disruption-driven platform built to organize, empower, and formalize India's informal construction labor ecosystem. By replacing traditional, uncertain physical labour chowks with a transparent digital marketplace, DLC provides craftsmen with regular work, 0% commission, and direct wage security while offering contractors and builders instant access to verified, skill-graded manpower.

---

## ⚡ Tech Stack

* **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
* **Library**: React 19
* **Language**: TypeScript
* **Styling**: Tailwind CSS
* **Icons**: [Lucide React](https://lucide.dev/)
* **Media & Video**: Embedded Vimeo Player API
* **Multilingual Engine**: Native client-side Google Web Translation Engine with 12 Indian regional languages

---

## 🌟 Key Features

1. **One-Click Multilingual Translation**:
   * Header quick-toggle for instant English (`EN`) and Hindi (`हिन्दी`).
   * Dedicated dropdown with 12 supported regional languages including **Bhojpuri (भोजपुरी)** and **Maithili (मैथिली)**, Marathi, Bengali, Punjabi, Gujarati, Telugu, Tamil, Odia, and Urdu.
   * Cookie-persisted language selection across navigation.

2. **Landing Experience**:
   * **Hero Canvas**: 6:57 min cinematic Vimeo documentary stream with interactive audio mute/unmute toggle.
   * **Popular Searches**: 2-row, 3-col trade showcase with high-res PNG cutouts and vernacular trade names (Masons, Carpenters, Steel Fixers, Electricians/Plumbers, Helpers).
   * **Bharat Ke Super Founders Banner**: Full edge-to-edge desktop presentation with a high-definition documentary popup modal.
   * **3-Pillar 3D Bento Grid**: Stakeholder showcase tailored for Workers (`काम ढूंढें`), Contractors (`मजदूर पाएं`), and Enterprises (`बिजनेस पार्टनर`) with live counts, trust chips, and value propositions.
   * **Live Stats Marquee**: Continuous right-to-left moving data ticker with active metric badges.
   * **Testimonials Carousel**: Real contractor, engineer, and tradesman reviews with smooth carousel navigation.
   * **App Download CTA**: 3D smartphone mockup with scannable QR code and Google Play / App Store badges.

3. **Complete "About Us" Ecosystem**:
   * `/about-us`: Master About Us Hub with origins, milestones, and video spotlights.
   * `/about-us/history`: Interactive chronological timeline spanning 2020 to 2026.
   * `/about-us/vision-mission`: Corporate vision, mission, and core values.
   * `/about-us/team`: Team leadership and engineering profiles.
   * `/about-us/leadership`: Founders and executive advisory.
   * `/about-us/awards`: National recognition, government felicitations (Hitachi, NAREDCO, DPIIT).
   * `/about-us/media`: Press coverage, news headlines, and media kit.
   * `/about-us/investors`: Shareholder updates, governance, and partner inquiries.
   * `/about-us/careers`: Open job positions, cultural manifesto, and hiring pipeline.

4. **Legal & Compliance Suite**:
   * Dedicated legal hub with sidebar navigation for `/terms-and-conditions`, `/privacy-policy`, `/cancellation-policy`, `/refund-policy`, and `/disclaimer`.

## 🚀 Getting Started

### Prerequisites
* Node.js 18.17+ or Node.js 20+
* npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/suryanmandal/digitallabourchowkv2.git
cd digitallabourchowkv2

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Build for production
npm run build

# Start production server
npm start
```
